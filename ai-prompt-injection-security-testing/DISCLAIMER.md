# Disclaimer

This repository is a **portfolio-safe reconstruction** created for public demonstration of defensive AI security testing methods.

## Data and Content Boundaries

This repository contains:
- Synthetic prompts and toy test cases
- Mock chatbot behavior
- Sample findings generated from local simulation
- Publicly known security concepts and references

This repository does **not** contain:
- Employer code, data, prompts, logs, screenshots, tickets, or findings
- Private chatbot outputs from company systems
- Real vulnerabilities from non-public environments
- Customer, employee, or partner information
- Credentials, tokens, API keys, internal URLs, or cloud identifiers

## Usage Scope

All examples are synthetic or based on public security learning concepts.

This repository is provided for:
- Defensive security education
- Portfolio demonstration
- Interview discussion of AI security and GRC practices

It is **not** intended to support unauthorized access, exploitation, or operational abuse of any real system.
