# Executive Summary (US-Global, Audit/GRC Style)

This repository presents a public, sanitized reconstruction of **prompt-injection and jailbreak security testing** suitable for portfolio and hiring review. The assessment concentrates on direct override attacks, system prompt extraction attempts, indirect injection through RAG/web/files, and prompt-to-tool action hijack patterns.

The project uses a local mock chatbot and synthetic data only. No employer, customer, or confidential material is included.

## Key Outcomes

- Demonstrates a repeatable local test harness for AI control validation.
- Applies a weighted residual-risk method based on Likelihood x Impact and observed control effectiveness.
- Produces evidence artifacts aligned for both technical security review and GRC reporting.
- Maps findings to OWASP LLM risk themes and ISO/IEC 27001 control themes.

## Governance Value

From a GRC perspective, this project shows how AI testing evidence can be translated into risk-register entries, remediation priorities, and control-assurance narratives suitable for audit and management stakeholders.

## Portfolio Relevance

This is intentionally structured to demonstrate practical capability for AI Security Engineer and GRC Analyst roles in US/global hiring contexts.
